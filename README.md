# CAM-B · 路径工艺平台

**路径即图形**的工艺上位机：画出来的路径绑定「工具」，工具在路径两端控制输出通道 + 延时。

核心特征：**每条路径的起点和终点各控制一个 IO + 一个延时**——开气阀后驻留等压力建立，关气阀后驻留等余压泄掉。这是气压驱动 DIW（Direct Ink Writing）打印的关键控制点。

> 🔧 **接手开发的 AI / 开发者请先读 [`docs/AI交接文档.md`](docs/AI交接文档.md)**
> 里面写了项目现状、代码地图、不能碰的红线、硬件的所有真相、已知的坑和下一步优先级。
>
> 🎯 **一句话现状**：软件功能完整、与 H5 板通信已验证，但**还没打出过任何真实工件**，硬件标定一项都没做。

## 它能做什么

- **画路径**：线段、矩形、圆，自由编辑
- **四种填充**：格栅（薄壁多孔）、蜂窝、平行扫描（实心）、同心轮廓（实心）
- **导入**：SVG 矢量图、STL/OBJ 3D 模型（自动逐层切片）
- **3D 预览**：看成品效果，可逐层查看
- **仿真回放**：看针头怎么走、气阀什么时候开关
- **生成 G-code**：五种方言可切换（H5 / R7 网口板 / F1 串口板 / Marlin / Klipper）
- **下发到机器**：UDP 直连开发板，或使用内置模拟板（无需硬件）
- **机器设置**：行程、轴方向反转、原点开关、软限位

## 快速开始

### 方式一：直接运行（推荐）

双击下载到的 `CAM-B-*-dist.exe`（从 [Releases](../../releases) 下载），浏览器会自动打开。

### 方式二：从源码运行

```bash
pip install fastapi uvicorn shapely pydantic
python -m uvicorn app.server:app --host 127.0.0.1 --port 8765
```

然后浏览器打开 http://127.0.0.1:8765

## 三步做出第一个打印路径

1. 左边选「矩形」，在画布上拖出一个方框
2. 点「填充选中形状」，内部织出打印线
3. 点右上「生成 G-code」，自动跳到 3D 预览看成品

**想复刻薄壁多孔格栅块**：画个方块 → 点右侧橙色「⚡ 一键套用格栅块参数」（会自动缩放到 8mm 见方）→ 填充 → 生成。

## 连接机器

开发板走**网口不是 USB**：

```
电脑 ──网线──> 开发板（192.168.0.102:5000）
```

板子不支持 DHCP，需要手动把电脑网卡配成 `192.168.0.x/24`。

**没有板子也能验证**：右侧「连接机器」面板勾选「用模拟板」，软件会自己扮演那块板子，可以完整跑通下发流程。

详见 [使用手册](docs/使用手册.md)。

## 架构

四层管线，层与层之间是纯数据，可独立测试：

```
画布编辑器  →  笔画列表  →  路径编译器  →  G-code 文本  →  下发器
（两端 IO 事件）              （方言可插拔）              （UDP 一发一等）
```

关键设计：**`caps.queued_io` 一个字段区分全部硬件**。

| `queued_io` | 硬件 | 行为 |
|---|---|---|
| `true` | Klipper | IO 随运动排队，不插 `M400`，不停车 |
| `false` | Marlin / 自研板 | 每条 IO 前插 `M400`，终点前切成段停车关阀 |

换硬件只需改这个配置，代码不用动。

```
app/
  model.py       数据模型（Project/Layer/Stroke/IOEvent）
  geometry.py    离散、扫描线填充、排序
```

## 技术栈

- **前端**：原生 JS + Canvas 2D，零框架零构建；3D 是手写透视投影
- **后端**：Python 3.14 + FastAPI + Uvicorn + Shapely + Pydantic
- 切片、SVG 解析、格栅填充、G-code 编译全部手写

## 已知限制

- **不支持 PNG/JPG 位图描边**（可先用 Inkscape 转成 SVG）
- 圆弧（G2/G3）在编译阶段就离散成折线，因为目标板不支持
- 单条运动估算超过 60 秒会被板子拒收，慢速长线需要切段

## 待确认的硬件参数

以下需要向硬件提供方确认，会影响最终效果：

1. 第 4 轴（固件里的 E / 现场标的 U）驱动什么——如果是注射器推杆，可以按体积控制，逻辑完全不同
2. IOOUT 8 路的分配——至少需要 2 路：主挤出阀 + 排气阀
3. 阀的电气特性——3.3V 逻辑需经 MOS/继电器，高电平开还是关、常闭常开
4. `M121` 是解析器执行还是队列同步——决定 `queued_io` 取值
5. 真机行程与原点开关
