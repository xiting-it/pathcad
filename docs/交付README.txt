CAM-B —— 路径工艺平台
================================================

这个文件夹里有三样东西：

  1. {{EXE}}     ← 软件本体，双击就能用
  2. 文档/           ← 说明书，双击里面的「0-从这里开始.html」
  3. 示例模型/       ← 6 个 STL 模型，可以直接导入试用


一、怎么启动
------------------------------------------------

  双击 {{EXE}}

  会弹出一个黑色命令行窗口，那是后台服务在跑。
  【不要关它】，关了软件就停了。

  等 2-3 秒，浏览器自动打开界面。
  如果没自动打开，手动访问：http://127.0.0.1:8765

  想关掉软件：关掉那个黑色窗口即可。


二、没有板子也能先玩
------------------------------------------------

  打开软件后，在右侧「连接机器」里勾上「用模拟板」。
  软件会自己扮演那块板子，可以完整跑一遍：

      画图 → 填充 → 生成 G-code → 发送 → 看进度条

  只是机器不会真的动。这是拿到板子之前最好的练习方式。


三、想先拿复杂模型试试
------------------------------------------------

  示例模型/ 里有 6 个现成的 STL：

      02-齿轮.stl        20 层 · 30x30x8mm   ← 先试这个，最快
      04-环面.stl        35 层 · 中间是通的
      05-格栅立方.stl    60 层 · 立体格栅，和视频那款同构
      06-星形花器.stl    87 层 · 5 角星截面
      01-花瓶.stl       100 层 · 10 条竖棱
      03-扭曲塔.stl     112 层 · 方塔扭转 135 度

  导入：点工具条「3D 模型」→ 选文件 → 点「填所有层」→「生成 G-code」

  注意：不填充就是空壳（只有外壁）。齿轮约 40 分钟，
  其他 1-2 小时，这是真实打印时间，不是软件卡住了。


四、接真板子
------------------------------------------------

  网口板（主力，能控制气阀）：
    - 用【网线】连，不是 USB
    - 电脑网卡配静态 IP  192.168.0.100 / 255.255.255.0
    - 软件里填 192.168.0.102，端口 5000
    - 详细步骤看 文档/3-交付说明.html

  F1 串口板：
    - USB 串口，COM 口，115200
    - 注意：这块板【没有 IO 输出】，控制不了气阀，只能做纯运动

六、重要提醒
------------------------------------------------

  ！两个会让板子卡死的操作，只能断电重启：

     - 网口板发 G4 指令（软件已避免生成，但手动指令框里别乱发）
     - F1 板空载发 G28（没有限位开关时会一直往负方向走，坐标报废）

  ！第一次上真机，先只接气阀不装针头，
     用「机器状态」页的「全开 / 全关」确认阀的动作对不对。

  ！气阀的通道号（0-7）、高电平是开还是关，必须确认接对了再谈打印。


七、软件做了什么
------------------------------------------------

  核心特点：每条路径的【起点】控制一个 IO + 一个延时，
            每条路径的【终点】再控制一个 IO + 一个延时。

  也就是说，开阀 → 等一下 → 走这一笔 → 停 → 关阀 → 等一下 → 抬针。
  这个"两头各挂一个 IO 事件"的做法，是给气动挤出（DIW）专门设计的，
  现成的切片软件和 3D 打印上位机都做不到。
