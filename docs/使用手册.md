## 第一章 · 五分钟做出第一个打印路径

### 第 0 步：打开

双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:8765`。

第一次打开会看到一个引导卡片，点「我自己画」关掉它。

![首次打开](01-首次打开.png)

### 第 1 步：画一个矩形

左边工具栏点「矩形」，然后在中间的黑色画布上**按住左键拖出一个方框**，松开。

![拖出矩形](03-拖出矩形.png)

松手后你会看到：

- 画布上出现一个蓝色方框
- 左下角出现「下一步：已选中形状。点填充选中形状」
- 左边「形状列表」里多了一行「矩形」

![矩形完成](04-矩形完成.png)

### 第 2 步：填满它

点左边那个橙色的「填充选中形状」按钮。

画布里会多出一排绿色横线 —— 这些就是**实际会挤出来的墨线**。蓝色是外框（轮廓），绿色是内部填充。

![填充完成](06-填充完成.png)

### 第 3 步：生成并看效果

点右上角蓝色的「生成 G-code」按钮。

**界面会自动跳到 3D 预览**，你会看到一叠蓝色的线，那就是打出来的东西。

![3D预览](07-3D预览.png)

用鼠标**拖动可以旋转**，滚轮缩放。上面有个「层」滑块，可以一层一层看。

![3D换个角度](08-3D换个角度.png)

### 完成

到这里，你已经完成了一个完整的流程：**画形状 → 填充 → 生成 → 看效果**。

真正的 G-code 在下面「G-code」标签里，可以复制走。

## 第二章 · 这个软件到底在干什么

### 它不是什么

它**不是**切片软件。切片软件是「给它一个 3D 模型（STL），它帮你切成一层层的」。

它**是**路径编辑器。你直接画**线**，它把这些线变成机器能执行的指令。

### 为什么需要这个

普通的 3D 打印机，喷头一直在出料，靠一个叫 E 轴的马达控制出多少。

你这台机器不一样：**它靠气阀开关来控制出不出料**。

- 开阀 → 开始出料
- 关阀 → 停止出料

所以每画一条线，机器需要知道：

1. 这条线从哪开始、到哪结束
2. **到起点时：打开气阀，等多久**（等气压建立、墨咬住底板）
3. **到终点时：关闭气阀，等多久**（等余压泄掉，不然会拖一条尾巴）

**这个软件就是让你画出这些线，并且给每条线的两端设定「开关阀 + 等多久」。**

### 一个形象的类比

想象你拿一支挤奶油的裱花袋，在蛋糕上画图案：

- 你**按下**裱花袋（开阀）
- **停一下**让奶油开始流出来（延时）
- **移动**手画出线条
- 到终点**松开**（关阀）
- **停一下**让多余的奶油断掉（延时）
- **抬起来**去下一个位置

软件做的就是把这些动作翻译成机器指令。

## 第三章 · 界面每一块是干什么的

整个界面分四块：

```
┌─────────────────────────────────────────────────┐
│ 顶栏：文件操作 + 生成按钮                        │
├────────┬──────────────────────┬─────────────────┤
│        │                      │                 │
│ 左边   │     中间画布          │    右边         │
│ 工具栏 │   （你画图的地方）    │  属性 / 提示    │
│        │                      │                 │
│        ├──────────────────────┤                 │
│        │   下边：结果查看      │                 │
└────────┴──────────────────────┴─────────────────┘
```

### 顶栏

| 按钮 | 作用 |
|---|---|
| **示例** | 载入一个做好的格栅块，直接看效果 |
| **新建** | 清空，从零开始 |
| **打开** | 载入之前保存的 `.json` 工程 |
| **保存** | 把当前工程存成 `.json` |
| **导入 SVG** | 把矢量图导进来变成路径 |
| **生成 G-code** | 最重要！把图变成机器指令并仿真 |

右边那个小徽章显示当前状态（「就绪」「生成中」「已生成 12 笔画」）。

### 左边：工具栏

四个工具，一次只能用一种：

| 工具 | 怎么用 |
|---|---|
| **选择** | 点线可以选中它，按住拖动可以移动整个形状 |
| **线段** | 拖出一条直线 |
| **矩形** | 拖出一个方框 |
| **圆** | 从圆心往外拖 |

下面是「填充选中形状」按钮和填充方式下拉框。

再往下是「形状列表」—— 你画的所有东西都在这，点一下就能选中。

最下面是折叠的「高级参数」，平时不用管。

### 中间：画布

**上半部分是编辑区**（2D），**下半部分是结果区**。

画布上的颜色含义：

| 颜色 | 含义 |
|---|---|
| 🔵 蓝色线 | 轮廓（外框） |
| 🟢 绿色线 | 填充线 |
| ⬜ 白色小方块 | 一条路径的**起点**（在这里开阀） |
| 🟠 橙色小圆点 | 一条路径的**终点**（在这里关阀） |

**操作**：
- 滚轮 = 缩放
- 右键拖动 或 Shift+拖动 = 平移画布
- 选中一个形状后，右侧面板可以改它的参数

### 右边：属性面板

**最上面是「下一步」提示** —— 它会告诉你现在该干什么，还会给一个可点的按钮。**不知道该干嘛就看这里。**

选中形状后，会出现两块卡片：

- **起点 · 开阀**（绿点）：通道号、电平、延时
- **终点 · 关阀**（橙点）：通道号、电平、延时

再往下是「诊断」（有问题会显示黄字）和「输出目标」（选机器类型）。

### 下边：结果区

四个标签页：

| 标签 | 看什么 |
|---|---|
| **时间轴** | 机器的速度曲线 + 气阀什么时候开什么时候关 |
| **路径俯视** | 从正上方看所有走过的路，实线是出料，虚线是空驶 |
| **单笔画放大** | 把一条线的开头和结尾放大，看延时对不对 |
| **G-code** | 最终生成的机器指令文本 |

## 第四章 · 那些参数到底是什么意思

### 最常改的 4 个

| 参数 | 默认 | 什么意思 | 什么时候改 |
|---|---|---|---|
| **开阀延时** | 120 ms | 开阀后等多久才开始移动 | 起点线条太细/有缺口 → **调大**；起点鼓包 → **调小** |
| **关阀延时** | 80 ms | 关阀后等多久才抬针 | 终点拖尾/拉丝 → **调大**；终点断口 → **调小** |
| **打印速度** | 600 mm/min | 画线时走多快 | 太慢会堆料，太快会断线。**先别动** |
| **填充间距** | 1.5 mm | 两条填充线之间隔多远 | 想更密 → 调小；想更快 → 调大 |

### 延时到底在补偿什么

气动系统有两个「反应慢」：

**开阀时**：气压要建立、墨水要从料筒挤到针尖 —— 需要时间。所以开阀后**先停一下再走**，否则起点会缺一段。

**关阀时**：管路里还有余压，会继续挤一点 —— 所以关阀后**先停一下再抬针**，否则会拖一条尾巴。

这两个数字**跟材料、针径、气压都有关**，没有万能值。同一台机器换个材料就要重调。

### 高级参数（一般不用碰）

| 参数 | 说明 |
|---|---|
| 空驶速度 | 阀关着的时候跑多快（可以很快） |
| 加速度 | 机器加速的快慢。太快会抖动 |
| 线宽 | 3D 预览用的，不影响 G-code |
| 层高 | 3D 预览用的 |
| 抬针 | 画完一条线抬多高去下一条 |
| 填充角度 | 平行扫描的方向（0° 是水平） |
| 填充内缩 | 填充线离外框留多远 |
| 层 Z 高度 | 这一层在哪个高度 |
| 重复层数 | 同一层画几遍（堆高度） |
| 层间增量 | 每多一层抬高多少 |

### 两个「通道/电平」是什么

这是控制气阀的硬件信号：

- **通道**：气阀接在第几路输出上（0–7）
- **电平**：1 = 高电平（一般代表开），0 = 低电平（关）

**除非你知道硬件接线，别改这两个。** 默认起点 1、终点 0 是对的。

## 第五章 · 怎么看懂结果

### 3D 预览

![3D预览](07-3D预览.png)

这是**打出来的样子**。颜色从深蓝到亮蓝表示从低到高。

- 拖动旋转
- 滚轮缩放
- 上面的滑块可以只看某一层

**怎么判断好不好**：看线条是否均匀、层与层是否对齐。如果有明显的粗细变化，说明速度或延时需要调。

### 时间轴

![仿真时间轴](09-仿真时间轴.png)

**上面那条蓝色曲线是速度**（快慢），**下面的方波是气阀状态**（高=开，低=关）。

**怎么判断对不对**：

- 气阀的「开」应该发生在速度**开始上升之前**（提前开阀）
- 气阀的「关」应该发生在速度**降到零之后**（走完再关）
- 如果「关」发生在速度还在跑的时候，说明关阀太早了

### 单笔画放大

![单笔画放大](10-单笔画放大.png)

这个视图把**一条线的开头和结尾**拉开放大，直接标出：

- `开阀 → 开始运动: XXXms` —— 这就是你的开阀延时实际值
- `运动停止 → 关阀: XXXms` —— 这就是你的关阀延时实际值

**这是调延时最有用的视图。** 改参数后重生成，看这两个数字对不对。

### G-code

![G代码](11-G代码.png)

最终机器指令。`;` 开头的行是注释，不会执行。

关键指令：

```
M121 U0 V1     ← 打开第 0 路（开阀）
G4 P120        ← 停 120 毫秒
G1 X8 Y0 F600  ← 走到 (8,0)，速度 600
M121 U0 V0     ← 关闭第 0 路（关阀）
G4 P80         ← 停 80 毫秒
```

`M400` 是「等运动完全停止」。在某些固件上必须加，否则开关阀的时机不准。

## 第六章 · 导入 SVG 和 3D 模型

### 导入 SVG

点顶栏「SVG」，选一个 `.svg` 文件。

![SVG导入](13-SVG导入.png)

导入后每个路径变成一个形状，可以：

- 选中后填充（选「同心轮廓」效果更好）
- 改延时
- 生成 G-code

![SVG填充3D](14-SVG填充3D.png)

**支持**：path、rect、circle、ellipse、line、polyline、polygon，以及 translate/scale/rotate/matrix 变换。

**不支持**：文字（`<text>`）、位图（`<image>`）、`<use>` 引用。如果导入后提示「忽略了 text」，需要先在 Inkscape 里选中文字 → 路径 → 对象转路径。

### 导入 3D 模型（Blender 导出的 STL / OBJ）

点顶栏「**3D 模型**」，选一个 `.stl` 或 `.obj` 文件。

**这是给 Blender 用户准备的**：你在 Blender 里建好模型，导出成 STL 或 OBJ，这里会自动把它**一层层切开**，每层变成一圈轮廓。

导入后：

1. 软件会告诉你切了多少层、模型尺寸多大
2. 每层变成工程里的一个图层，可以逐层查看
3. 点「生成 G-code」就能直接打印

**注意**：切出来的是**轮廓**（外框），不是实心的。如果想让每一层内部也填满，需要：

- 选中某层的轮廓
- 点「填充选中形状」

或者直接用薄壁打印（只打外框，靠层间堆积成壳）。

**参数影响**：切片层高取「层与高度 → 层高」的值（默认 0.4mm）。改这个值再重新导入，层数会变。

**从 Blender 导出的建议**：

- 导出前把模型**摆正**（Z 轴朝上），原点放在底面中心或一角
- 尺寸按毫米建模，导出时缩放选 1.0
- 用 **STL（二进制）** 最省事，OBJ 也支持
- 模型必须是**封闭实体**（有体积），平面或开放网格切不出东西

### 关于图片（PNG/JPG）

**目前还不支持直接导入位图**。如果要从图片生成路径，现在的做法是：

1. 用 Inkscape 打开图片
2. 选中图片 → 路径 → **临摹位图**（Trace Bitmap）
3. 调整阈值后确定
4. 删掉原图，保存成 SVG
5. 导入这个 SVG

如果你需要，我可以直接做「图片自动描边」功能，说一声。

## 第七章 · 撤销、重做和步数

### 顶栏中间那三个东西

```
[↶] [↷]  3 步
```

- **↶ 撤销**：退回上一步（快捷键 `Ctrl+Z`）
- **↷ 重做**：把撤销掉的恢复回来（快捷键 `Ctrl+Shift+Z` 或 `Ctrl+Y`）
- **3 步**：你现在在第几步。数字越大说明改动越多

### 什么会被记成一步

**每一步**都是可以撤销的：

- 画一个形状
- 移动一个形状（拖动整段算一步，不是每像素一步）
- 删除一个形状
- 填充
- 改任何一个参数（连续拖同一个滑块算一步）
- 改笔画属性（连续输入同一个框算一步）
- 导入 SVG / 3D 模型
- 新建 / 载入工程
- 恢复默认参数

### 最多能退多少步

**120 步**。超过之后最早的会被丢掉（不是出错，只是退不回去了）。

### 两个细节

**拖滑块不会产生几十步**：你在「开阀延时」上从 120 拖到 200，中间经过几十个值，但只记**一步**。松手后停 0.7 秒，下次拖才是新的一步。

**撤销后如果又做了新操作，原来的「重做」就没了**。这是正常的历史行为——就像文字编辑器一样。

### 如果发现撤销不了

看右上角步数：
- 显示 `0 步` → 已经退到最开始了
- 按钮是灰的 → 没有可撤销/重做的

## 第八章 · 连接机器并真正打印

### 先搞清楚：这个软件怎么和机器说话

**不是 USB 线，是网线。**

你的开发板用的是一个叫 `LAN8720A` 的以太网芯片，板子上写死的 IP 是 `192.168.0.102`，端口 `5000`。

```
电脑 ──网线──> 开发板
```

板子**不支持自动分配 IP**（没有 DHCP），所以要手动配电脑的网卡：

1. Windows 打开「网络和 Internet 设置」→「更改适配器选项」
2. 右键你的网卡 →「属性」→「Internet 协议版本 4 (TCP/IPv4)」
3. 选「使用下面的 IP 地址」：
   - IP 地址：`192.168.0.100`
   - 子网掩码：`255.255.255.0`
   - 网关：留空
4. 确定

> ⚠️ 如果电脑同时连着 WiFi 上网，配完之后可能上不了网。这时需要加一条路由规则，或者用完之后改回「自动获得 IP」。

### 没有板子也能验证：模拟板

**这是最重要的一点**：你可以不接板子，就把整个流程跑通。

在右侧「连接机器」面板里，勾上「**用模拟板**」。

软件会自己扮演那块板子，监听 `127.0.0.1:5000`。你可以：

- 点「探活」—— 看能不能通
- 点「发送到机器」—— 把 G-code 真正"发出去"
- 看进度条走完、有没有错误
- 用「手动指令」发 `M121 U0 V1` 看气阀响应

**模拟板完全照着通信协议文档实现**，所以你在这里测通的流程，接上真板子改个 IP 就能跑。

### 连真板子

1. 网线连好，板子上电
2. 右侧 IP 填 `192.168.0.102`，端口 `5000`
3. 点「**连接**」
4. 点「**探活**」确认返回 `E000`

看到绿色的连接点，说明通了。

### 发送 G-code

1. 先生成 G-code
2. 点「**发送到机器**」
3. 看进度条：`X/Y 行`，右侧显示当前在执行哪一行
4. 有错误会列在「诊断」区

**发送策略是「发一行等一行」**：发一条指令，等板子回 `E000` 确认执行完，再发下一条。

为什么不用并发？因为协议里**结果包不带票号**，并发时一旦丢包就无法对应。一发一等最稳。

**想中止**：点「中止发送」。

### 手动发指令（调试用）

面板最下面的「手动指令」，可以直接发一行，比如：

| 指令 | 作用 |
|---|---|
| `M114` | 查当前位置 |
| `M120` | 读所有 IO |
| `M121 U0 V1` | 打开第 0 路气阀 |
| `M121 U0 V0` | 关闭第 0 路气阀 |
| `M400` | 等运动停止 |

**上真机第一步就该这么做**：发 `M121 U0 V1` 再发 `M121 U0 V0`，看气阀有没有动作、通道号对不对。

## 第九章 · 常见问题

### 点「生成 G-code」没反应 / 报错

**先看右边「诊断」区**，那里会写原因。最常见的是：

- 「先画个形状」—— 你还没画东西
- 「填充为空」—— 形状太小，内缩把区域吃掉了。把形状画大点，或把「填充内缩」调小

### 3D 预览是空的

3D 只在「生成 G-code」之后才有内容。如果生成过还是空的，切到「2D 编辑」再切回「3D 预览」刷新一下。

### 填充只出来一条线

正常。如果你画的是很小的形状，平行扫描的几行会被连成一条连续折线（这样效率最高，只开关阀一次）。

想让每行独立开关阀 → 画大一点，或者把「填充间距」调小。

### 画完的东西找不到了

看左边「形状列表」。如果列表是空的，说明被「新建」清掉了。

**记得点「保存」**，工程会存成 `.json` 文件。

### 界面卡住了

刷新浏览器（F5）。工程没保存会丢，所以养成随手保存的习惯。

### 想让示例重新出现

点顶栏「示例」按钮，会载入一个做好的格栅块工程。

## 第十章 · 上真机之前

### 先别急着接机器

软件里看到的都是**仿真**，不是真机。上真机前请按这个顺序：

1. **空跑**（不装材料、不装针头）
   把 G-code 发到机器，看运动轨迹和软件里画的对不对。

2. **只测气阀**
   手动发 `M121 U0 V1` → 等 1 秒 → `M121 U0 V0`，听声音、看指示灯。
   确认通道号接对了。

3. **标定延时**（最重要）
   用单根 20mm 直线，只改开阀延时，从 0 到 300ms 打一组，看起点哪种最均匀。
   然后固定开阀延时，用同样方法测关阀延时。

4. **才画复杂图形**

### 三个必须问清楚的事

- **气阀接在哪一路？**（软件里的「通道」要对上）
- **高电平是开还是关？**（接反了会一直出料或者一直不出）
- **断电时气阀是什么状态？**（必须是关，否则断电会漏料）

### 标定数据要存下来

不同材料、不同针径、不同气压，延时都不一样。

建议每测出一组，就用「保存」存一个工程文件，文件名写清楚，比如 `凝胶-0.4针-0.6MPa.json`。下次换回来直接「打开」。
