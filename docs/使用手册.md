## 第一章 · 五分钟做出第一个打印路径

### 第 0 步：打开

双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:8765`。

第一次打开会看到一个引导卡片，点「我自己画」关掉它。

![首次打开](01-首次打开.png)

### 第 1 步：画一个矩形

左边工具栏点「矩形」，然后在中间的黑色画布上**按住左键拖出一个方框**，松开。

![拖出矩形](03-拖出矩形.png)

松手后你会看到：

- 画布上出现一个蓝色方框
- 左下角出现「下一步：已选中形状。点填充选中形状」
- 左边「形状列表」里多了一行「矩形」

![矩形完成](04-矩形完成.png)

### 第 2 步：填满它

点左边那个橙色的「填充选中形状」按钮。

画布里会多出一排绿色横线 —— 这些就是**实际会挤出来的墨线**。蓝色是外框（轮廓），绿色是内部填充。

![填充完成](06-填充完成.png)

### 第 3 步：生成并看效果

点右上角蓝色的「生成 G-code」按钮。

**界面会自动跳到 3D 预览**，你会看到一叠蓝色的线，那就是打出来的东西。

![3D预览](07-3D预览.png)

用鼠标**拖动可以旋转**，滚轮缩放。上面有个「层」滑块，可以一层一层看。

![3D换个角度](08-3D换个角度.png)

### 完成

到这里，你已经完成了一个完整的流程：**画形状 → 填充 → 生成 → 看效果**。

真正的 G-code 在下面「G-code」标签里，可以复制走。

## 第二章 · 这个软件到底在干什么

### 它不是什么

它**不是**切片软件。切片软件是「给它一个 3D 模型（STL），它帮你切成一层层的」。

它**是**路径编辑器。你直接画**线**，它把这些线变成机器能执行的指令。

### 为什么需要这个

普通的 3D 打印机，喷头一直在出料，靠一个叫 E 轴的马达控制出多少。

你这台机器不一样：**它靠气阀开关来控制出不出料**。

- 开阀 → 开始出料
- 关阀 → 停止出料

所以每画一条线，机器需要知道：

1. 这条线从哪开始、到哪结束
2. **到起点时：打开气阀，等多久**（等气压建立、墨咬住底板）
3. **到终点时：关闭气阀，等多久**（等余压泄掉，不然会拖一条尾巴）

**这个软件就是让你画出这些线，并且给每条线的两端设定「开关阀 + 等多久」。**

### 一个形象的类比

想象你拿一支挤奶油的裱花袋，在蛋糕上画图案：

- 你**按下**裱花袋（开阀）
- **停一下**让奶油开始流出来（延时）
- **移动**手画出线条
- 到终点**松开**（关阀）
- **停一下**让多余的奶油断掉（延时）
- **抬起来**去下一个位置

软件做的就是把这些动作翻译成机器指令。

## 第三章 · 界面每一块是干什么的

![界面总览](new/01-界面总览.png)

界面分六层，从上到下、从左到右：

```
┌──────────────────────────────────────────────────────┐
│ ① 菜单栏   文件 编辑 视图 绘制 机器 帮助             │
├──────────────────────────────────────────────────────┤
│ ② 工具条   撤销 新建 示例 打开 保存 SVG 3D模型 全选   │
├──────────────────────────────────────────────────────┤
│ ③ 选项条   当前工具 + 提示 + 随工具变化的参数         │
├────────┬──────────────────────────┬──────────────────┤
│ ④工具  │  ⑤ 画布（标尺 + 网格）    │ ⑥ 参数面板       │
│ 竖排   │                          │  摘要卡/属性/参数 │
│ 10个   ├──────────────────────────┤                  │
│        │  输出面板（可折叠）       │                  │
├────────┴──────────────────────────┴──────────────────┤
│ 底部状态栏  坐标 缩放 网格 吸附 对象数 输出目标 连接  │
└──────────────────────────────────────────────────────┘
```

### ① 菜单栏

所有功能都在这，找不到按钮时来这里翻。快捷键写在菜单项右边。

### ② 工具条

| 按钮 | 作用 |
|---|---|
| 撤销 / 重做 + 步数 | 操作可回溯，旁边显示当前第几步 |
| **新建** | 清空，从零开始 |
| **示例** | 载入一个做好的格栅块，直接看效果 |
| **打开** / **保存** | `.json` 工程文件 |
| **SVG** | 把矢量图导进来变成路径 |
| **3D 模型** | 导入 STL/OBJ 并切片 |
| **全选** | 选中所有路径 |

### ③ 工具选项条（PS 那种）

跟着当前工具变：

- 选「多边形」→ 出边数；选「星形」→ 出角数
- **右边常驻「旋转 [n]° + −」** —— 所有图形都能转
- 选中形状时出「填充选中形状」「填所有层」
- 最右显示选中对象的尺寸和中心坐标

### ④ 左侧工具栏（10 个）

| 工具 | 快捷键 | 怎么用 |
|---|---|---|
| 选择 | V | 点中形状拖动移动 |
| 点 | P | 一下一个墨点 |
| 线段 | L | 拖一条直线 |
| 矩形 | R | 拖一个方框 |
| 圆 | C | 从圆心拖出半径 |
| 椭圆 | E | 从中心拖出长短轴 |
| 多边形 | G | 从中心拖出，边数在选项条改 |
| 菱形 | D | 拖出两条对角线 |
| 星形 | S | 从中心拖出外半径，角数在选项条改 |
| 填充 | F | 油漆桶，点哪个填哪个 |

### ⑤ 画布

**标尺**在上边和左边，单位毫米，刻度随缩放自适应。
**网格**默认 5mm 一格，可切 1/5/10mm。
**工作台边界**是那个淡蓝色框，标注了实际行程（200 × 200 mm）。

> 标尺和网格**只在「2D 编辑」页出现**。切到 3D 预览、仿真、机器状态时自动隐藏，不挡内容。

四个页签在画布左上角：`2D 编辑` / `3D 预览` / `仿真` / `机器状态`。

画布上的颜色含义：

| 颜色 | 含义 |
|---|---|
| 蓝色线 | 轮廓（外框） |
| 绿色线 | 填充线 |
| 橙色小点 | 起点（在这里开阀） |
| 黄色小点 | 终点（在这里关阀） |

**操作**：滚轮缩放 · 中键或 Shift+拖动平移 · 画线时按住 Shift 强制水平/垂直

### ⑥ 右侧参数面板

**最上面是「本次将打印」摘要卡**——一眼看清会打几层、多高、多久：

| 字段 | 说明 |
|---|---|
| **层数** | 带 `−` / `+` 按钮，也能直接输。**改这里就是改要打几层** |
| 总高度 | 层数 × 层高，实时算 |
| 笔画 / 预计耗时 | 耗时超过 5 分钟变橙色提醒 |
| 层高 / 起始Z | 微调用 |

下面那一行人话状态会告诉你现在该干嘛（"还没画东西 → 画好了 → 已生成 → 已就绪"）。

再往下依次是：下一步提示 → 对象列表 → 选中形状的属性 → 参数分组（打印质量/填充/层与高度/运动）→ 诊断 → 输出目标 → 连接机器（默认折叠）→ 发送按钮。

### 底部状态栏

常驻一行关键数值：光标坐标、缩放比例、网格大小、吸附开关、对象数、已选、输出目标、连接状态。

工业软件都有这一条，作用是**不用点开任何面板就能确认当前状态**。

### 输出面板

可折叠（点 `⤢` 展开）。四个标签：

| 标签 | 看什么 |
|---|---|
| **时间轴** | 速度曲线 + 气阀开关时机 |
| **路径俯视** | 从正上方看所有走过的路 |
| **单笔画放大** | 把一条线首尾放大，看延时对不对 |
| **G-code** | 生成的机器指令原文 |
| **输出** | 底层通讯日志 |

## 第四章 · 那些参数到底是什么意思

### 最常改的 4 个

| 参数 | 默认 | 什么意思 | 什么时候改 |
|---|---|---|---|
| **开阀延时** | 120 ms | 开阀后等多久才开始移动 | 起点线条太细/有缺口 → **调大**；起点鼓包 → **调小** |
| **关阀延时** | 80 ms | 关阀后等多久才抬针 | 终点拖尾/拉丝 → **调大**；终点断口 → **调小** |
| **打印速度** | 600 mm/min | 画线时走多快 | 太慢会堆料，太快会断线。**先别动** |
| **填充间距** | 1.5 mm | 两条填充线之间隔多远 | 想更密 → 调小；想更快 → 调大 |

### 延时到底在补偿什么

气动系统有两个「反应慢」：

**开阀时**：气压要建立、墨水要从料筒挤到针尖 —— 需要时间。所以开阀后**先停一下再走**，否则起点会缺一段。

**关阀时**：管路里还有余压，会继续挤一点 —— 所以关阀后**先停一下再抬针**，否则会拖一条尾巴。

这两个数字**跟材料、针径、气压都有关**，没有万能值。同一台机器换个材料就要重调。

### 高级参数（一般不用碰）

| 参数 | 说明 |
|---|---|
| 空驶速度 | 阀关着的时候跑多快（可以很快） |
| 加速度 | 机器加速的快慢。太快会抖动 |
| 线宽 | 3D 预览用的，不影响 G-code |
| 层高 | 3D 预览用的 |
| 抬针 | 画完一条线抬多高去下一条 |
| 填充角度 | 平行扫描的方向（0° 是水平） |
| 填充内缩 | 填充线离外框留多远 |
| 层 Z 高度 | 这一层在哪个高度 |
| 层间增量 | 每多一层抬高多少 |

> **层数（重复打几遍）在右栏顶部的「本次将打印」摘要卡里改**，带 `−`/`+` 按钮。参数面板里不再放第二份，免得两边不一致。

### 旋转图形

![旋转功能](new/04-旋转功能.png)

顶部选项条右上有「**旋转 [0] ° + −**」：

- **选中形状时** → 直接转它，`+`/`−` 每次 15°，也可以输任意角度
- **没选中时** → 设的是「下一个画的图形」的默认角度

所有 8 种图形都支持。正数逆时针，负数顺时针。

转过之后形状会记成「多边形」（转过的矩形已经不是矩形了），不影响填充和打印。

### 四种填充方式，该选哪个

| 方式 | 长什么样 | 什么时候用 |
|---|---|---|
| **格栅** | 外框 + 内部互相垂直的筋，中间是孔洞 | **要打视频里那种薄壁多孔块** |
| 蜂窝 | 六边形格子 | 要更均匀的孔、更高的强度 |
| 平行扫描 | 一排平行线填满 | 要打实心片 |
| 同心轮廓 | 一圈圈往里缩 | 要打实心但有轮廓感的 |

### 格栅填充的三个参数（最容易搞错）

**间距** —— 这是**筋与筋之间的距离**，也就是**孔的大小**，**不是线宽**。

> 很多人以为调小间距是"线变粗"，其实是"孔变小、筋变密"。

参考值：视频里那台机器用的是 **2mm**。

**内缩** —— 筋离外框留多远。太小会和外框粘在一起，太大会出现空隙。

**错开** —— 勾上之后，横筋和竖筋错开半格，孔洞分布更均匀。

### ⚡ 一键套用格栅块参数

如果你就是想打出视频里那个效果，别自己调参数，点这个按钮。

它会自动做四件事：

1. 填充方式切成「格栅」，间距 2mm
2. 速度、延时、线宽、层高都设成视频那台的量级
3. 层设置成 6 层
4. **把你画的形状自动缩放到 8mm 见方**

第 4 点很重要。视频里那个格栅块**只有 8mm 见方**。如果你随手画了个 80mm 的方块再套 2mm 格栅，会得到 900 笔画、4 小时的任务，而且 3D 预览会糊成一片。

### 两个「通道/电平」是什么

这是控制气阀的硬件信号：

- **通道**：气阀接在第几路输出上（0–7）
- **电平**：1 = 高电平（一般代表开），0 = 低电平（关）

**除非你知道硬件接线，别改这两个。** 默认起点 1、终点 0 是对的。

## 第五章 · 怎么看懂结果

### 3D 预览

![3D预览](07-3D预览.png)

这是**打出来的样子**。颜色从深蓝到亮蓝表示从低到高。

- 拖动旋转
- 滚轮缩放
- 上面的滑块可以只看某一层

**怎么判断好不好**：看线条是否均匀、层与层是否对齐。如果有明显的粗细变化，说明速度或延时需要调。

### 时间轴

![仿真时间轴](09-仿真时间轴.png)

**上面那条蓝色曲线是速度**（快慢），**下面的方波是气阀状态**（高=开，低=关）。

**怎么判断对不对**：

- 气阀的「开」应该发生在速度**开始上升之前**（提前开阀）
- 气阀的「关」应该发生在速度**降到零之后**（走完再关）
- 如果「关」发生在速度还在跑的时候，说明关阀太早了

### 单笔画放大

![单笔画放大](10-单笔画放大.png)

这个视图把**一条线的开头和结尾**拉开放大，直接标出：

- `开阀 → 开始运动: XXXms` —— 这就是你的开阀延时实际值
- `运动停止 → 关阀: XXXms` —— 这就是你的关阀延时实际值

**这是调延时最有用的视图。** 改参数后重生成，看这两个数字对不对。

### G-code

![G代码](11-G代码.png)

最终机器指令。`;` 开头的行是注释，不会执行。

关键指令：

```
M121 U0 V1     ← 打开第 0 路（开阀）
G4 P120        ← 停 120 毫秒
G1 X8 Y0 F600  ← 走到 (8,0)，速度 600
M121 U0 V0     ← 关闭第 0 路（关阀）
G4 P80         ← 停 80 毫秒
```

`M400` 是「等运动完全停止」。在某些固件上必须加，否则开关阀的时机不准。

## 第六章 · 导入 SVG 和 3D 模型

### 导入 SVG

点顶栏「SVG」，选一个 `.svg` 文件。

![SVG导入](13-SVG导入.png)

导入后每个路径变成一个形状，可以：

- 选中后填充（选「同心轮廓」效果更好）
- 改延时
- 生成 G-code

![SVG填充3D](14-SVG填充3D.png)

**支持**：path、rect、circle、ellipse、line、polyline、polygon，以及 translate/scale/rotate/matrix 变换。

**不支持**：文字（`<text>`）、位图（`<image>`）、`<use>` 引用。如果导入后提示「忽略了 text」，需要先在 Inkscape 里选中文字 → 路径 → 对象转路径。

### 导入 3D 模型（Blender 导出的 STL / OBJ）

点顶栏「**3D 模型**」，选一个 `.stl` 或 `.obj` 文件。

**这是给 Blender 用户准备的**：你在 Blender 里建好模型，导出成 STL 或 OBJ，这里会自动把它**一层层切开**，每层变成一圈轮廓。

导入后：

1. 软件会告诉你切了多少层、模型尺寸多大
2. 每层变成工程里的一个图层，可以逐层查看
3. 点「生成 G-code」就能直接打印

**注意**：切出来的是**轮廓**（外框），不是实心的。如果想让每一层内部也填满，需要：

- 选中某层的轮廓
- 点「填充选中形状」

或者直接用薄壁打印（只打外框，靠层间堆积成壳）。

**参数影响**：切片层高取「层与高度 → 层高」的值（默认 0.4mm）。改这个值再重新导入，层数会变。

**从 Blender 导出的建议**：

- 导出前把模型**摆正**（Z 轴朝上），原点放在底面中心或一角
- 尺寸按毫米建模，导出时缩放选 1.0
- 用 **STL（二进制）** 最省事，OBJ 也支持
- 模型必须是**封闭实体**（有体积），平面或开放网格切不出东西

### 关于图片（PNG/JPG）

**目前还不支持直接导入位图**。如果要从图片生成路径，现在的做法是：

1. 用 Inkscape 打开图片
2. 选中图片 → 路径 → **临摹位图**（Trace Bitmap）
3. 调整阈值后确定
4. 删掉原图，保存成 SVG
5. 导入这个 SVG

如果你需要，我可以直接做「图片自动描边」功能，说一声。

## 第七章 · 撤销、重做和步数

### 顶栏中间那三个东西

```
[↶] [↷]  3 步
```

- **↶ 撤销**：退回上一步（快捷键 `Ctrl+Z`）
- **↷ 重做**：把撤销掉的恢复回来（快捷键 `Ctrl+Shift+Z` 或 `Ctrl+Y`）
- **3 步**：你现在在第几步。数字越大说明改动越多

### 什么会被记成一步

**每一步**都是可以撤销的：

- 画一个形状
- 移动一个形状（拖动整段算一步，不是每像素一步）
- 删除一个形状
- 填充
- 改任何一个参数（连续拖同一个滑块算一步）
- 改笔画属性（连续输入同一个框算一步）
- 导入 SVG / 3D 模型
- 新建 / 载入工程
- 恢复默认参数

### 最多能退多少步

**120 步**。超过之后最早的会被丢掉（不是出错，只是退不回去了）。

### 两个细节

**拖滑块不会产生几十步**：你在「开阀延时」上从 120 拖到 200，中间经过几十个值，但只记**一步**。松手后停 0.7 秒，下次拖才是新的一步。

**撤销后如果又做了新操作，原来的「重做」就没了**。这是正常的历史行为——就像文字编辑器一样。

### 如果发现撤销不了

看右上角步数：
- 显示 `0 步` → 已经退到最开始了
- 按钮是灰的 → 没有可撤销/重做的

## 第八章 · 连接机器并真正打印

### 先搞清楚：你要连的是哪块板

**软件支持三种板子，接线方式和能力完全不同。** 先对号入座：

| 板子 | 怎么接 | 能控气阀？ | 延时谁做 | 适合 |
|---|---|---|---|---|
| **网口板**（i.MX RT1170） | 网线 | ✅ 8 路 | 软件（上位机等） | **推荐主力** |
| **F1 板**（STM32F103） | USB 串口 | ❌ 不能 | 无 | 只能验证运动 |
| Marlin / Klipper | 看机器 | ✅ | 板子 | 现成 3D 打印机 |

在右侧「输出目标」下拉里选对应的板子，编译器会按它的能力生成不同的 G-code。

---

### 情况一：网口板（推荐）

**不是 USB 线，是网线。**

板子上写死的 IP 是 `192.168.0.102`，端口 `5000`，走 UDP。

```
电脑 ──网线──> 开发板
```

板子**不支持自动分配 IP**（没有 DHCP），所以要手动配电脑网卡：

1. Windows 打开「网络和 Internet 设置」→「更改适配器选项」
2. 右键**接板子的那块网卡** →「属性」→「Internet 协议版本 4 (TCP/IPv4)」
3. 选「使用下面的 IP 地址」：
   - IP 地址：`192.168.0.100`
   - 子网掩码：`255.255.255.0`
   - 网关：留空
4. 确定

> ⚠️ **两个常见坑**
>
> **坑 1：WiFi 抢路由。** 如果你的 WiFi 也在 `192.168.0.x` 网段，Windows 可能把发往板子的包走 WiFi，永远连不上。判断方法：`ping 192.168.0.102` 不通，但网线指示灯是亮的。
>
> **坑 2：网卡配错。** 电脑可能有多块网卡（以太网、以太网 2、vEthernet…）。一定要配**插了网线、状态显示"已连接"**的那一块。

**连接步骤**：

1. 网线连好，板子上电
2. 右侧「连接方式」选「**网络（UDP）**」
3. IP 填 `192.168.0.102`，端口 `5000`
4. 点「**连接**」，再点「**探活**」确认返回 `E000`

---

### 情况二：F1 串口板

**这根是 USB 线（板子上是 CH340 芯片）。**

1. USB 插上，Windows 会自动认成 `COMx`
2. 右侧「连接方式」选「**串口（F1 板）**」
3. 串口下拉里，带 **★** 的那个就是板子（软件会自动识别 CH340/CP210 芯片）
4. 波特率 `115200`
5. 点「**连接**」

> ⚠️ **F1 板不能控制气阀**——它的协议里只有 `G00/G01/G02/G28/M50` 五个指令，没有任何 IO 输出。用它就只是空跑轨迹，不会出料。
>
> ⚠️ **空载时千万不要发 `G28`**。没有限位开关，板子会一直往负方向走到保护上限，坐标被搞成 -6000，之后所有指令都报 `E05` 拒收，**只能断电重启**。

---

### 没有板子也能验证：模拟板

**这是最重要的一点**：你可以不接板子，就把整个流程跑通。

在右侧「连接机器」面板里，勾上「**用模拟板**」。

软件会自己扮演那块板子，监听 `127.0.0.1:5000`。你可以：

- 点「探活」—— 看能不能通
- 点「发送到机器」—— 把 G-code 真正"发出去"
- 看进度条走完、有没有错误
- 用「手动指令」发 `M121 U0 V1` 看气阀响应

**模拟板完全照着通信协议文档实现**，所以你在这里测通的流程，接上真板子改个 IP 就能跑。

---

### 发送 G-code

1. 先生成 G-code
2. 点「**发送到机器**」
3. 看进度条：`X/Y 行`，右侧显示当前在执行哪一行
4. 有错误会列在「诊断」区

**关于发送策略**：

| 板子 | 策略 | 原因 |
|---|---|---|
| 网口板 | 一包发 6 条 | 每条指令板内固定开销约 200-360ms，批量能摊薄 |
| F1 板 | 发一条等一条 | 严格一问一答半双工，运动中发指令会回 `E07` |

**想中止**：点「中止发送」。

**想看底层在干什么**：切到底部「**输出**」标签页，能看到每一条指令的收发原文。打开 `HEX` 开关还能看到原始字节。

---

### 手动发指令（调试用）

面板最下面的「手动指令」，可以直接发一行：

| 指令 | 作用 | 哪块板 |
|---|---|---|
| `M114` | 查当前位置 | 网口板 |
| `M120` | 读所有 IO（含 IOOUT 掩码） | 网口板 |
| `M121 U0 V1` | 打开第 0 路气阀 | 网口板 |
| `M121 U0 V0` | 关闭第 0 路气阀 | 网口板 |
| `M121 V255` | 8 路一次全开 | 网口板 |
| `M50` | 查限位 + 坐标 | F1 板 |
| `G28` | 回原点 | F1 板（**空载别发**） |

**上真机第一步就该这么做**（网口板）：发 `M121 U0 V1` 再发 `M120`，看 `IOOUT` 是不是变成 `0x01`；再发 `M121 U0 V0` 看是否回 `0x00`。这样能确认气阀接线和通道号都对。

---

### 延时是怎么实现的（重要）

**每条路径的起点开阀后要等一下再走（上升延时），终点关阀后也要等一下（拖尾延时）。这个延时在哪执行，取决于板子：**

| 板子 | 延时实现 | 精度 |
|---|---|---|
| 网口板 | **软件等**（发完 `M121` 收到 `E000` 后，Python 侧 sleep） | 实测误差 < 1ms |
| 支持 `G4` 的板 | 板内 `G4 P120` | 微秒级 |
| F1 板 | 无（直接忽略） | — |

**这意味着**：用网口板时，G-code 文件里**没有 `G4` 指令**，延时只在软件发送时才生效。所以**单独把 G-code 拷给别人跑，是没有延时的**。

如果你需要一份「自带延时」的 G-code，把输出目标切到 Marlin 或 Klipper，重新生成即可。

## 第九章 · 常见问题

### 点「生成 G-code」没反应 / 报错

**先看右边「诊断」区**，那里会写原因。最常见的是：

- 「先画个形状」—— 你还没画东西
- 「填充为空」—— 形状太小，内缩把区域吃掉了。把形状画大点，或把「填充内缩」调小

### 3D 预览是空的

3D 只在「生成 G-code」之后才有内容。如果生成过还是空的，切到「2D 编辑」再切回「3D 预览」刷新一下。

### 填充只出来一条线

正常。如果你画的是很小的形状，平行扫描的几行会被连成一条连续折线（这样效率最高，只开关阀一次）。

想让每行独立开关阀 → 画大一点，或者把「填充间距」调小。

### 画完的东西找不到了

看左边「形状列表」。如果列表是空的，说明被「新建」清掉了。

**记得点「保存」**，工程会存成 `.json` 文件。

### 界面卡住了

刷新浏览器（F5）。工程没保存会丢，所以养成随手保存的习惯。

### 想让示例重新出现

点顶栏「示例」按钮，会载入一个做好的格栅块工程。

---

### 连不上板子怎么办

**网口板（ping 不通）**

按顺序排查：

1. **网线指示灯亮不亮？** 不亮说明线或口有问题
2. **电脑网卡配的是哪一块？** 右键任务栏网络图标 →「打开网络和 Internet 设置」→「更改适配器选项」，看哪个网卡是"已连接"。可能是「以太网 2」而不是「以太网」
3. **WiFi 是不是抢了路由？** 如果 WiFi 也在 `192.168.0.x`，发往板子的包会走 WiFi。临时关掉 WiFi 试试
4. **ping 通了但软件连不上？** 检查端口是不是 `5000`

**F1 串口板（打不开串口）**

- 报 `PermissionError(13, '拒绝访问')` → **上一个进程还占着串口**。关掉其他串口工具（串口助手、Arduino IDE、另一个 CAM-B 窗口），或者拔插一次 USB
- 下拉里找不到 COM 口 → 检查 USB 线（有些线只能充电不能传数据）、装 CH340 驱动

### 板子发指令没反应了

**网口板**：很可能发了 `G4`。这块板**不支持 G4**，发了之后队列会卡死、所有指令都没响应，**只能断电重启**。

**F1 板**：很可能发过 `G28`。空载没限位开关时会跑到保护上限，坐标变成 -6000，之后所有移动指令都报 `E05` 拒收，**只能断电重启**。

### 为什么发送这么慢

**每条指令板内固定开销约 200-360ms**，这是固件决定的，不是网络问题。

软件已经做了优化：一包发 6 条（`batch_size=6`），把开销摊薄。但总量还是受指令条数限制。

**想更快**：画小一点、减少层数、把填充间距调大（筋少了，指令就少了）。

### 打印出来的线宽不均匀

**如果斜线比直线细**，这是板子的 `F` 值语义问题（待确认）：`F` 可能被解释成"最快轴速度"而不是"合速度"，导致斜线实际速度更快、出料更少。

**如果起止点有积料或断料**，调「起点·开阀延时」和「终点·关阀延时」——这是 DIW 最关键的参数，必须针对每种材料标定。

## 第十章 · 上真机之前

### 先别急着接机器

软件里看到的都是**仿真**，不是真机。上真机前请按这个顺序：

1. **空跑**（不装材料、不装针头）
   把 G-code 发到机器，看运动轨迹和软件里画的对不对。

2. **只测气阀**
   手动发 `M121 U0 V1` → 等 1 秒 → `M121 U0 V0`，听声音、看指示灯。
   确认通道号接对了。

3. **标定延时**（最重要）
   用单根 20mm 直线，只改开阀延时，从 0 到 300ms 打一组，看起点哪种最均匀。
   然后固定开阀延时，用同样方法测关阀延时。

4. **才画复杂图形**

### 三个必须问清楚的事

- **气阀接在哪一路？**（软件里的「通道」要对上）
- **高电平是开还是关？**（接反了会一直出料或者一直不出）
- **断电时气阀是什么状态？**（必须是关，否则断电会漏料）

### 标定数据要存下来

不同材料、不同针径、不同气压，延时都不一样。

建议每测出一组，就用「保存」存一个工程文件，文件名写清楚，比如 `凝胶-0.4针-0.6MPa.json`。下次换回来直接「打开」。
