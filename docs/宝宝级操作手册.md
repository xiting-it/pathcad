# CAM-B 宝宝级操作手册

> 这份手册假设你**从来没摸过任何设计软件**。
> 每一步都告诉你：点哪里、会看到什么、为什么这么做。
> 看不懂的地方直接看图，图里标了红圈。

---

## 第 0 章 · 这软件是干什么的

一句话：**你画一个形状，软件把它变成机器能走的路线，机器照着路线挤出材料。**

最典型的用法：画一个 8mm 的方块 → 软件在里面填上一横一竖的筋 → 机器沿着筋打出一个「格栅块」。

**你不需要懂 G-code，不需要懂 CAM，会画方块就够了。**

---

## 第 1 章 · 认识屏幕（先看图）

![界面总览](new/01-界面总览.png)

整个软件分 6 块，从左到右：

| 区域 | 在哪 | 干什么 |
|---|---|---|
| **① 菜单栏** | 最顶上（文件 编辑 视图 绘制 机器 帮助） | 所有功能都能在这里找到 |
| **② 工具条** | 菜单栏下面 | 撤销、新建、保存这些常用按钮 |
| **③ 工具栏** | 最左边一竖排 | 画图用的笔：线段、矩形、圆…… |
| **④ 画布** | 中间大黑区域 | 在这里画形状 |
| **⑤ 参数面板** | 最右边 | 调速度、延时这些数字 |
| **⑥ 输出面板** | 底部 | 看软件和机器说了什么话 |

**画布上面和左边的刻度是标尺**，单位是毫米。你画的东西有多大，看标尺就知道。

**画布右上有三个开关**：网格、吸附、网格大小。默认全开，不用动。

> 标尺和网格只在「2D 编辑」这一页出现。切到 3D 预览、仿真、机器状态时它们会自动隐藏，不会挡着内容。

**四个页签在画布左上角**：`2D 编辑` / `3D 预览` / `仿真` / `机器状态`。点一下切换。

## 第 2 章 · 五分钟打出第一个东西

跟着做，每一步只用 10 秒。

### 第 1 步：画一个方块

1. 点左边工具栏的「**矩形**」（图标 ▭）
2. 鼠标移到画布中间
3. **按住左键**，往右下拖
4. 松开

![拖拽指示器](new/03-拖拽指示器.png)

拖的时候你会看到：
- **橙色虚线方框**——将要画出的形状
- **旁边一个黄色小牌**——实时显示「80.00 × 55.00 mm」这样的尺寸
- 起点和终点各有一个小圆点

**不用管精确尺寸**，下一步会让它自动变准。

### 第 2 步：套用「格栅块」参数

1. 点右边参数区的橙色按钮「**⚡ 一键套用「格栅块」参数**」

它会自动做四件事：
- 填充方式改成格栅
- 间距设为 2mm
- 速度、延时都设成视频那台的量级
- **把你画的方块缩放成 8mm 见方**

### 第 3 步：填充

1. 点左边的「**填充选中形状**」按钮

画布上会出现绿色的横竖筋——这就是机器要走的路线。

### 第 4 步：生成 G-code

1. 点右上角蓝色大按钮「**生成 G-code**」

右侧「诊断」区会显示：`60 笔画 · 729.6mm · 约 79s`。
同时画布自动切换到「**3D 预览**」，你能看到成品长什么样。

### 第 5 步：先看看机器会怎么走

1. 点顶部的「**仿真**」标签
2. 点「▶ 播放」

你会看到一个小点沿着路线跑，**气阀什么时候开、什么时候关**都在右边实时显示。这是不接板子就能看的效果。

**到这里你已经完成全部流程了。** 接下来的章节讲怎么保存、怎么连机器。

## 第 3 章 · 保存和打开

### 保存

1. 点工具条的「**保存**」（或菜单栏 文件 → 保存工程）
2. 浏览器会下载一个 `.json` 文件
3. 文件名建议写清楚材料，比如 `凝胶-0.4针.json`

### 打开

1. 点「**打开**」，选之前存的 `.json`

> ⚠️ 软件不会自动保存。**画完就存**，不然刷新页面就没了。

## 第 4 章 · 画图工具详解

左边工具栏有 10 个，常用的就 5 个：

| 工具 | 图标 | 怎么用 | 快捷键 |
|---|---|---|---|
| **选择** | ➤ | 点形状选中，拖动移动 | V |
| **矩形** | ▭ | 按住拖一个框 | R |
| **圆** | ◯ | 从圆心拖出半径 | C |
| **线段** | ╱ | 按住拖一条线 | L |
| **填充** | ▨ | 点哪个形状就填哪个（油漆桶） | F |

不太常用的：

| 工具 | 说明 |
|---|---|
| 点 | 一下就是一个墨点（打点阵用） |
| 椭圆 | 从中心拖出长轴短轴 |
| 多边形 | 从中心拖出半径，边数在顶部选项条里改（3-20 边） |
| 菱形 | 拖出两条对角线 |
| 星形 | 角数在顶部选项条里改 |

### 画图时的三个好东西

**① 吸附**：你画的东西会自动对齐到 5mm 网格，所以画出来永远是整数尺寸。关掉的话就是 37.38mm 这种数。

**② 端点吸附**：画的终点靠近已有形状的角时，会自动贴上去。

**③ Shift 正交约束**：画线时按住 Shift，线会强制水平或垂直。

### 转角度（旋转）

![旋转功能](new/04-旋转功能.png)

顶部选项条右上角有「**旋转 [0] ° + −**」：

- **选中一个形状** → 点 `+` / `−` 每下转 15°，也可以在框里直接输任意角度（-360 到 360）
- **没选中任何东西** → 你设的角度会变成「下一个画的图形」的默认角度

**所有 8 种图形都能转**：矩形、圆、椭圆、多边形、菱形、星形、点、线段。

正数是**逆时针**，负数是顺时针。

用途举例：
- 画一个 45° 斜的菱形，做交叉筋
- 把六边形转 30° 变成「尖角朝上」或「平边朝上」
- 把星形转个角度让放射线错开

> 转过之后的形状会记成「多边形」，因为转过的矩形已经不是矩形了。这不影响填充和打印。

### 选中之后能干什么

点一个形状选中它，右边会出两块面板：

**「位置 尺寸」卡**：
- 直接输入中心 X/Y 和宽/高，**回车生效**
- 🔒 比例锁亮着时，改宽会自动等比改高

**「起点·开阀 / 终点·关阀」卡**：
- 通道：气阀接在第几路（0-7）
- 延时：开阀后等多久再走 / 关阀后等多久再抬
- 这两个延时是 DIW 最关键的参数，每种材料都要标定

## 第 5 章 · 填充

### 四种填充方式

| 方式 | 效果 | 用途 |
|---|---|---|
| **格栅** | 外框 + 内部横竖筋，中间是孔 | 打视频里那种多孔块 |
| 蜂窝 | 六边形格子 | 要更均匀的孔 |
| 平行扫描 | 一排排平行线填满 | 打实心片 |
| 同心轮廓 | 一圈圈往里缩 | 打实心但有轮廓感 |

### 「间距」是什么意思

**间距 = 孔的大小 = 筋和筋的距离**，**不是线宽**。

视频那台用的是 2mm。间距越小越密越慢，越大越疏越快。

预设：0.1 / 0.2 / 0.3 / 0.5 / 0.8 / 1 / 2 mm，也有「自定义」滑块。

## 第 6 章 · 两个延时（DIW 的灵魂）

气动系统反应慢，所以：

- **开阀后要等一下再走**（不然起点缺一段料）→ 「起点·开阀延时」
- **关阀后要等一下再抬**（不然拖一条尾巴）→ 「终点·关阀延时」

**怎么标定**：

1. 画一根 20mm 的直线
2. 开阀延时从 0 开始，每次加 50ms，打一根
3. 看哪一根的**起点**最均匀 → 那个就是你的开阀延时
4. 固定它，同样方法测关阀延时（看**终点**有没有拖尾）

**不同材料、不同针径、不同气压，这两个数都不一样。**

### 一键覆盖

调好一个值之后，点「**应用到全部起点**」或「**应用到全部终点**」，所有路径一次改完。

## 第 7 章 · 连接机器

### 先选对板子

右侧「输出目标」下拉：

| 选项 | 谁用 |
|---|---|
| **网口板（i.MX RT1170）** | 网线连的那块（**默认，推荐**） |
| F1 串口板 | USB 串口连的那块（**不能控气阀**） |
| Marlin / Klipper | 现成的 3D 打印机 |

### 网口板怎么连

**用网线，不是 USB。**

1. 网线连好，板子上电
2. 给电脑网卡配静态 IP：`192.168.0.100`，掩码 `255.255.255.0`
   （Windows：设置 → 网络 → 更改适配器选项 → 右键网卡 → 属性 → IPv4）
3. 软件里 IP 填 `192.168.0.102`，端口 `5000`
4. 点「**连接**」→ 再点「**探活**」

连接成功后，底部状态栏右边会变成绿色的「**已连接**」。

> ⚠️ 连不上先查两件事：①网线插的是哪块网卡（可能叫「以太网 2」）；②WiFi 是不是也在 192.168.0.x 网段（会抢路由）。

### 机器状态页

![机器状态](new/05-机器状态.png)

点顶部的「**机器状态**」标签，能看到：

- **24 个 IO 指示灯**（输出 8 + 输入 8 + 原点 8），亮 = 高电平
- **底层通讯日志**：软件和板子说的每一句话
- 快捷按钮：读全部 / 全关 / 全开 / 查坐标

**接气阀后第一步**：点「全开」，看气阀有没有动作；再点「全关」。确认接线对了再谈打印。

### 没有板子也能测（模拟板）

在「连接机器」里勾上「**用模拟板**」，软件会自己扮演那块板子。

可以完整走一遍 画图 → 填充 → 生成 → 发送，进度条会正常走。**只是不会真的动**。

这是拿到板子之前最好的练习方式。

### 发送

1. 生成 G-code 后点「**发送到机器**」
2. 进度条会走，底部「输出」面板能看到每一条指令
3. 想中途停：点「中止发送」

默认显示「**输出**」标签（日志）。可以切到：

## 第 10 章 · 出问题了看这里

| 现象 | 原因 | 解决 |
|---|---|---|
| 点连接没反应 | 网卡没配 IP / WiFi 抢路由 | 见第 7 章 |
| 报「连不上」 | 板子没上电 / IP 不对 | ping 192.168.0.102 试试 |
| 3D 预览是空的 | 还没生成 G-code | 点「生成 G-code」 |
| 填充是空的 | 形状太小，内缩吃掉了 | 画大点，或调小「填充内缩」 |
| 发送超时 | 板子卡死 | **断电重启板子** |
| 画的东西找不到了 | 刷新了页面没保存 | 画完就存 |

**板子没反应时**：网口板发过 `G4` 会卡死；F1 板发过 `G28` 会跑飞。都只能**断电重启**。

## 第 11 章 · 名词表（看不懂别人的话时查）

| 词 | 意思 |
|---|---|
| **G-code** | 机器能看懂的指令文本，一行一个动作 |
| **笔画** | 一次落笔到抬笔的完整路线 |
| **IO** | 输入/输出引脚，气阀接在输出上 |
| **通道** | 气阀接在第几路 IO（0-7） |
| **驻留/延时** | 开阀或关阀后故意等待的时间 |
| **空驶** | 阀关着时的快速移动（不出料） |
| **行程** | 机器能走到的最大范围（本项目 200×200mm） |
| **原点** | (0,0) 的位置，标尺上的蓝色十字 |
| **探活** | 发一条查询指令看板子活没活 |

## 附：为什么这么设计（给好奇的人）

**为什么每个笔画都要「开阀延时」和「关阀延时」？**

气动系统不是即开即有的。开阀后气压要建立、墨水要从料筒流到针尖，需要几十到几百毫秒；关阀后管路里还有余压会继续挤。这两个延时就是在补偿这个物理过程。没有它们，每一笔的起点会缺料、终点会拖尾。

**为什么「以通信协议为准」？**

协议文档描述的是板子真正认识的指令格式。打印机的说明书描述的是"效果"，但效果可以有不同的实现路径。跟着协议走，至少每一条指令板子都认识。

**为什么用网页做界面？**

路径编辑需要大量的鼠标交互（拖拽、缩放、吸附），网页的 Canvas 是最成熟的方案。而且打包后双击就能用，不用装环境。
